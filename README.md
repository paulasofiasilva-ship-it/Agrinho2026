# 📖 Sobre o Projeto

O projeto **Campo Inteligente** foi desenvolvido para demonstrar como a tecnologia pode contribuir para uma agricultura mais sustentável, reduzindo impactos ambientais e promovendo o uso responsável dos recursos naturais.

O site apresenta informações educativas sobre agricultura sustentável, tecnologias utilizadas no campo e práticas que ajudam a aumentar a produção agrícola sem prejudicar o meio ambiente.

Além dos conteúdos informativos, o projeto possui um quiz interativo para que os visitantes possam testar seus conhecimentos sobre sustentabilidade e inovação tecnológica no setor agrícola.

---

# 🎯 Problema Abordado

A agricultura é fundamental para a produção de alimentos, porém algumas práticas podem causar impactos negativos ao meio ambiente, como:

* Desperdício de água;
* Degradação do solo;
* Uso excessivo de produtos químicos;
* Perda da biodiversidade;
* Poluição ambiental.

Diante desses desafios, a tecnologia surge como uma importante aliada para tornar a produção agrícola mais eficiente e sustentável.

---

# 🎯 Objetivo do Site

O objetivo principal do projeto é conscientizar os visitantes sobre a importância da tecnologia na agricultura sustentável, mostrando soluções que ajudam a preservar os recursos naturais e reduzir impactos ambientais.

Ao navegar pelo site, o usuário aprenderá sobre:

* Agricultura sustentável;
* Irrigação inteligente;
* Drones agrícolas;
* Sensores de monitoramento;
* Preservação dos recursos naturais;
* Benefícios ambientais das tecnologias no campo.

# 🚀 Funcionalidades

## Navegação por Seções

O site possui menu de navegação para facilitar o acesso aos conteúdos.

## Conteúdo Educativo

Apresenta textos explicativos sobre:

* Agricultura sustentável;
* Tecnologias agrícolas;
* Preservação ambiental;
* Uso consciente dos recursos naturais.

## Gráfico Ilustrativo

Representação visual simples dos benefícios que a tecnologia oferece ao meio ambiente e à produção agrícola.

## Quiz Interativo

O usuário pode responder perguntas relacionadas ao tema do projeto.

### Funcionamento do Quiz

1. O visitante responde às perguntas.
2. O JavaScript verifica as respostas.
3. A pontuação é calculada automaticamente.
4. O resultado é exibido na tela.
5. O usuário pode realizar o quiz novamente.

# 💻 Como Executar o Projeto

## Método 1 – Localmente

1. Baixe os arquivos do projeto.
2. Coloque todos os arquivos na mesma pasta.
3. Abra o arquivo `index.html`.
4. O site será carregado automaticamente no navegador.

## Método 2 – GitHub Pages

1. Faça upload dos arquivos para um repositório GitHub.
2. Acesse as configurações do repositório.
3. Abra a seção **Pages**.
4. Selecione a branch **main**.
5. Clique em **Save**.
6. Aguarde a publicação.
7. O GitHub fornecerá um link público para o site.
